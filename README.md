# Laboratorio di Simulazione Numerica - A.A. 2024/2025

Repository contenente le esercitazioni svolte da Lucrezia Bioni per il corso di **Simulazione Numerica** tenuto dal Prof. Galli nell'anno accademico 2024-2025.

## Struttura della Repository

Ogni cartella corrisponde a un'esercitazione e contiene:

1. Il codice sorgente dell'esercitazione (eventualmente diviso in sottocartelle)
2. Un notebook Jupyter (`.ipynb`) con:
   - Descrizione del problema
   - Risultati numerici
   - Visualizzazioni grafiche
3. Eventuali file di dati necessari
